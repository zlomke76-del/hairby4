# Editorial image brief

Generated with the built-in image-generation tool for this website concept, October 12, 2026.

Prompt: Create a premium hair salon editorial photographic contact sheet, precisely three columns by two rows, six edge-to-edge equal rectangles with no borders, gaps, text, logos or overlays. Landscape ratio 3:2. Six different adult hairstyles with natural warm ivory studio backgrounds: flowing brunette with caramel balayage; French dark bob and fringe; defined natural curls; copper layers and curtain bangs; men's textured taper; soft blonde waves and highlights. Detailed individual hair strands, approachable editorial photography and luminous lighting. Subjects contained within their own panels. Concept imagery, not photos of real salon customers.

The image is delivered in `dist/assets/editorial-hair.jpg`. CSS selects panels without fetching third-party images. Image generation returned a PNG; the delivered file was encoded as JPEG for smaller payload. All displayed model photos are explicitly identified as inspiration, not this salon's portfolio.
